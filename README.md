# 네이버 검색 랜덤 리다이렉트 시스템

토스 앱 리워드 미션처럼 매번 다른 검색어로 리다이렉트되는 짧은 링크를 생성하는 웹 애플리케이션입니다.

## 기능

- 짧은 랜덤 링크 생성 (예: `/r/ABC123`)
- 하나의 링크에 여러 개의 검색 키워드 조합 저장
- 링크 접속 시 랜덤으로 다른 네이버 검색 URL로 리다이렉트
- 클릭 통계 및 관리 대시보드
- 키워드 관리 (추가/수정/삭제)

## 설치 방법

1. 필수 패키지 설치:
```bash
pip install -r requirements.txt
```

2. 서버 실행:
```bash
python app.py
```

3. 브라우저에서 접속:
```
http://localhost:5000
```

## 사용 방법

### 1. 새 링크 생성

1. 사이드바에서 **"새 링크 생성"** 클릭
2. 상품명 입력 (선택사항)
3. 검색 키워드 조합 입력:
   - **Query**: 네이버 검색어 (예: "청소기 추천")
   - **Acq**: 자동완성 검색어 (예: "청소기 인기")
4. 필요하면 "키워드 추가" 버튼으로 더 추가
5. "랜덤 링크 생성" 버튼 클릭
6. 생성된 짧은 링크 복사

### 2. 링크 사용

생성된 링크를 누군가 클릭하면:
- 자동으로 네이버 모바일 검색으로 이동
- 매번 다른 키워드 중 랜덤으로 선택
- `ackey`, `acr` 파라미터는 자동으로 랜덤 생성

### 3. 링크 관리

1. 사이드바에서 **"링크 관리"** 클릭
2. 생성된 링크 목록 확인
3. "상세" 버튼으로 키워드 확인
4. "삭제" 버튼으로 링크 삭제

### 4. 대시보드

- 총 링크 수
- 총 키워드 수
- 총 클릭 수
- 오늘 클릭 수
- 최근 생성 링크

## URL 파라미터 설명

생성되는 네이버 검색 URL 구조:
```
https://m.search.naver.com/search.naver?
  sm=mtp_sug.top
  &where=m
  &query={입력한 Query}
  &ackey={영문+숫자 8글자 랜덤}
  &acq={입력한 Acq}
  &acr={0~10 랜덤 숫자}
  &qdt=0
```

- `query`: 실제 검색어 (직접 입력)
- `acq`: 자동완성 검색어 (직접 입력)
- `ackey`: 영문소문자+숫자 8글자 (자동 랜덤 생성)
- `acr`: 0~10 사이 숫자 (자동 랜덤 생성)
- `qdt`: 0 고정

## API 엔드포인트

- `GET /` - 메인 관리 페이지
- `GET /r/<code>` - 랜덤 리다이렉트
- `GET /api/stats` - 대시보드 통계
- `GET /api/links` - 모든 링크 조회
- `GET /api/links/<code>` - 특정 링크 상세
- `POST /api/links` - 새 링크 생성
- `DELETE /api/links/<code>` - 링크 삭제

## 예시

### 링크 생성 예시

**입력:**
- 상품명: "청소기"
- 키워드 1: Query="청소기 추천", Acq="청소기 인기"
- 키워드 2: Query="무선청소기", Acq="무선청소기 가성비"
- 키워드 3: Query="청소기 순위", Acq="청소기 브랜드"

**생성된 링크:** `http://localhost:5000/r/Abc123XYZ45`

**사용:**
- 1번째 클릭 → "청소기 추천" 검색
- 2번째 클릭 → "무선청소기" 검색
- 3번째 클릭 → "청소기 순위" 검색
- 4번째 클릭 → "청소기 추천" 검색 (랜덤)
- ...계속 랜덤으로 선택됨
